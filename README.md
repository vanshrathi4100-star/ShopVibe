🛍️ ShopVibe — Online Shopping Website

A clean and responsive e-commerce front-end project built using HTML, CSS, and JavaScript.

ShopVibe provides a simple and visually appealing shopping interface where users can explore different product categories through an organized layout and product images.

✨ Features

* 🛒 Multiple Categories — Electronics, clothing, shoes, watches, bags, books, toys, furniture, and more.
* 🔍 Category Search — Search and filter product categories by name.
* 🖼️ Visual Product Cards — Dedicated sections with images for each category.
* 📱 Responsive Styling — CSS media queries to improve the layout on smaller screens.
* 🎨 Clean Interface — Navigation bar, hero banner, category sections, and footer.
* ⚡ Smooth Navigation — Explore the collection using the page navigation link.

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all image files are present in the project folder.
4. Open index.html in your browser, or use the Live Server extension in VS Code.

🔍 Search Functionality

Use the search bar to find categories by name. The JavaScript filters the category cards according to the text entered.

🌐 Deployment

You can host this project for free using GitHub Pages.

1. Push the project files to a GitHub repository.
2. Open the repository’s Settings.
3. Select Pages.
4. Choose the deployment source and branch.
5. Save the settings and open the generated website link once deployment is complete.
